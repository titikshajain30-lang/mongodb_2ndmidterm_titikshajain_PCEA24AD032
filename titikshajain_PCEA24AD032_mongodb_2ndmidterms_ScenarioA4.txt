Scenario A4 – Banking App: Building and Checking a Replica Set

Database: bankDB
Replica Set Name:rs0
MongoDB Ports:27017 , 27018, 2701

Task 1:

Terminal 1:

mongod --replSet rs0 --port 27017 --dbpath C:\data\rs0-1 --bind_ip localhost

Terminal 2:

mongod --replSet rs0 --port 27018 --dbpath C:\data\rs0-2 --bind_ip localhost

Terminal 3:

mongod --replSet rs0 --port 27019 --dbpath C:\data\rs0-3 --bind_ip localhost


rs.initiate({
    _id: "rs0",
    members: [
        { _id: 0, host: "localhost:27017" },
        { _id: 1, host: "localhost:27018" },
        { _id: 2, host: "localhost:27019" }
    ]
})


rs.status()

Expected output

{
    ok: 1
}

Task 2: Identify PRIMARY and SECONDARY members

rs.status()

rs.status().members.forEach(m => {
    print({

    });
});

Task 3: Insert an account using majority write concern


use bankDB

db.accounts.insertOne(
    {
        accNo: 1001,
        holder: "Kumar",
        balance: 5000
    },
    {
        writeConcern: {
            w: "majority",
            wtimeout: 5000
        }
    }
)


output:

{
    acknowledged: true,
    insertedId: ObjectId("...")
}


Task 4: Set read preference to secondaryPreferred and read the account

db.getMongo().setReadPref("secondaryPreferred")

db.accounts.find({ accNo: 1001 }

Expected output:

[
    {
        _id: ObjectId("..."),
